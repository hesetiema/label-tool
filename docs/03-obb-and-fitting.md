# ③ 3D 框与几何算法

> 配套源码：`src/core/geometry/box.ts`

这一篇是**整个工具算法含量最高**的部分：3D 框怎么转成 8 个角点，以及"画个框自动贴合"背后的数学。

---

## 1. OBB 的 8 个角点

一个 OBB 由 `position + scale + yaw` 定义，但渲染线框、导出 JSON 都需要 8 个角点的具体坐标。怎么算？

**思路：先在局部坐标系里造 8 个点，再旋转、平移到世界坐标。**

局部坐标以框中心为原点，长(L=x)、宽(W=y)、高(H=z)：

```
       顶面 z=+H/2          底面 z=-H/2
   3 ┌────────┐ 2        7 ┌────────┐ 6
     │        │            │        │
   0 └────────┘ 1        4 └────────┘ 5
   (车头 x=+L/2)         (车尾 x=-L/2)
```

8 个点的局部坐标：

```
0: (+L/2, -W/2, -H/2)   4: (-L/2, -W/2, -H/2)
1: (+L/2, +W/2, -H/2)   5: (-L/2, +W/2, -H/2)
2: (+L/2, +W/2, +H/2)   6: (-L/2, +W/2, +H/2)
3: (+L/2, -W/2, +H/2)   7: (-L/2, -W/2, +H/2)
```

然后对每个点：

```
1) 绕 z 轴旋转 yaw：
   x' = x·cos(yaw) - y·sin(yaw)
   y' = x·sin(yaw) + y·cos(yaw)

2) 加上中心：
   world = position + (x', y', z)
```

`boxToVertices()` 就是这个过程的直接实现，输出顺序刻意与 SUSTechPOINTS 一致（车头面 4 点 + 车尾面 4 点），因此导出的 `vertices` 能被原仓库正确读取。

## 2. 自动框拟合（fitBoxToPoints）—— 交互的灵魂

当你在 BEV 上拖一个矩形，工具要"自动把框贴到车上"。怎么做？

### 核心技巧：换坐标系

在**世界坐标系**里，车是斜的，框也是斜的，直接算 min/max 会得到错误的巨大框。

但如果**把点变换到框的局部坐标系**（逆向旋转 yaw），框就变成轴对齐的了！这时候：

```
length = x 方向的 max - min
width  = y 方向的 max - min
height = z 方向的 max - min
center = 各方向的 (max + min) / 2
```

这正是 `fitBoxToPoints()` 做的事：

```
1) 逆旋转：把候选点用 -yaw 旋转到局部系
2) 统计局部系里 xyz 的 min/max
3) 反算中心和尺寸，再旋转回世界系
```

### 一个实用的改进：剔除地面点

BEV 框选时经常把路面点也框进去，导致 z 方向被拉低、框变得很扁。解决办法：先算这批点的 z 范围，丢掉最低的那一部分（比如最低 15%）：

```ts
const zCut = zMin + (zMax - zMin) * 0.15
if (pz < zCut) continue  // 跳过近地面点
```

这个简单的启发式，效果往往肉眼可见地变好。

## 3. PCA 估计主方向（estimateYawByPCA）

自动拟合需要一个初始 yaw。我们自己估计它，靠的是一个漂亮的数学工具：**PCA（主成分分析）**。

### 直觉

一辆车的点云，沿车身方向分布得"更长"，垂直于车身方向更"窄"。那么**点云方差最大的方向，就是车身朝向**。

### 计算步骤

```
1) 求 xy 的均值 (mx, my)，把点中心化
2) 构造 2×2 协方差矩阵：
     [ sxx  sxy ]
     [ sxy  syy ]
   其中 sxx = Σ(x-mx)², syy = Σ(y-my)², sxy = Σ(x-mx)(y-my)
3) 最大特征值对应的方向角：
     yaw = 0.5 · atan2(2·sxy, sxx - syy)
```

最后这个公式来自 2×2 对称矩阵特征向量的解析解。它让我们**不用深度学习，也能从点云里估出物体的朝向**——这也是原仓库早期 `algos/rotation.py` 的思路之一。

### 与深度学习的对比

| 方法 | 优点 | 缺点 |
|---|---|---|
| PCA | 快、无需训练、可解释 | 对不规则形状/遮挡敏感 |
| 深度学习 | 更鲁棒、能预测完整 3D 框 | 需要模型、训练数据、算力 |

原仓库的"自动偏航角预测"用的是 TensorFlow 模型（`deep_annotation_inference.h5`）。我们教学版用 PCA，让你先理解几何本质，再去看它的模型也不迟。

## 4. 判断点是否落在框内（pointInBoxBev）

点击选中框时要做命中检测。思路同样是换坐标系：

```
1) 把点击点相对框中心平移
2) 用 -yaw 逆旋转到局部系
3) 判断 |lx| <= L/2 且 |ly| <= W/2
```

因为存在重叠框，代码里用 `[...boxes].reverse().find()`——后画的框（视觉上在上层）优先被选中，符合直觉。
